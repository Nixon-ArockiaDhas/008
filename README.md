# 008Hub Website

Premium responsive single-page website for 008Hub, built with Next.js and designed for deployment on Vercel.

## Development

```bash
npm install
npm run dev
```

The development command listens on all network interfaces and prints both the local Mac URL and the Wi-Fi URL to open on an iPad connected to the same network.

## Production

```bash
npm run build
npm start
```

Vercel can deploy the repository using its standard Next.js defaults. No custom build command or output directory is required.
